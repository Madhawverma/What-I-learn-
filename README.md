# What-I-learn-01. Website clone karte time sabse pehle kya match karna hai?

→ Typography match karni hai — font, size, weight, line-height aur spacing.

02. GitHub par commit kaise karte hain?

→ git add .
→ git commit -m "message"

03. GitHub par code push kaise karte hain?

→ git push

04. GitHub se latest code pull kaise karte hain?

→ git pull

05. Model kya hota hai?

→ Model data ka structure/format define karta hai.

06. Multiple same-type items ko kaise handle karte hain?

→ Array/List mein multiple items store karte hain.

07. Same cheez multiple jagah use ho to kya karna hai?

→ Reusable component bana kar use multiple jagah use karo.

08. Backend mein Java, Python aur Node.js kaise run karte hain?

→ Java: javac File.java → java File
→ Python: python file.py
→ Node: node file.js

09. Navbar mein tab ka text ek hi line mein kaise rakhen?

→ white-space: nowrap; use karo.

10. Navbar mein line break kaise prevent karen?

→ Text/container par white-space: nowrap; lagao.

11. Website banate time sabse pehle kis cheez par focus karna hai?

→ Sabse pehle UI aur layout par focus karo.

12. Website mein animation kitni use karni chahiye?

→ Sirf jahan animation useful ho, wahi use karo.

13. Kahan animation use karna achha hota hai?

→ Splash screen, loading aur important interactions mein.

14. Kya har section ko animated banana chahiye?

→ Nahi, unnecessary animation avoid karo.

15. Normal website UI kaisi rakhni chahiye?

→ Clean, simple aur stable UI rakhni chahiye.

16. Same fields/divs ko kaise rakhna chahiye?

→ Same width, height, spacing, padding aur structure rakho.

17. Har page ka UI same hona chahiye?

→ Design system same rakho, lekin page ki requirement ke according UI customize karo.

18. Pre-boarding kya hota hai?

→ Main onboarding se pehle user ka initial setup/preparation process.

19. Onboarding kya hota hai?

→ New user ko app ke features aur basic working samjhane ka process.

20. HRMS mein kya-kya hona chahiye?

→ Employee, Attendance, Leave, Payroll, Recruitment, Onboarding, Performance, Documents, Roles & Reports.

21. APK aur iOS mein kya difference hai?

→ APK Android application package hai; iOS apps Apple platform ke liye hoti hain.

22. React.js aur React Native mein kya difference hai?

→ React.js websites ke liye hai.
→ React Native mobile apps ke liye hai.

23. React Native project kaise start karte hain?

→ Project setup ke liye React Native/Expo ki required CLI command use karke project create karte hain.

24. React.js project kaise start karte hain?

→ npm create vite@latest
→ npm install
→ npm run dev

25. Next.js project kaise create karte hain?

→ npx create-next-app@latest

26. Next.js project kaise run karte hain?

→ npm run dev

27. TypeScript kya hai?

→ JavaScript ka typed version hai jo types define karne deta hai.

28. Java program kaise run karte hain?

→ javac Main.java
→ java Main

29. Python program kaise run karte hain?

→ python file.py

30. Node.js program kaise run karte hain?

→ node server.js

31. MongoDB kya hai?

→ MongoDB ek NoSQL database hai jo data ko documents ke form mein store karta hai.

32. MongoDB mein data ka structure kya hota hai?

→ Database → Collection → Documents

33. Frontend aur backend ko kaise connect karte hain?

→ Frontend API request bhejta hai → Backend request process karta hai → Database se data leta/Save karta hai → Response frontend ko deta hai.

34. Live website ko update kaise karte hain?

→ Server par jaakar latest code pull → build → application restart/reload.

35. Server par /var kaise jaate hain?

→ cd /var

36. /www folder mein kaise jaate hain?

→ cd /www

37. Website ke folder mein kaise jaate hain?

→ cd <website-folder>

38. Latest GitHub code server par kaise laate hain?

→ git pull

39. Website ka production build kaise banate hain?

→ npm run build

40. Build ke baad kya karna hota hai?

→ PM2 se application ko restart/reload karna hota hai.

41. Live update ke baad browser mein kya karna hai?

→ Hard Refresh karna hai.

42. Live website update ka basic flow kya hai?

→ cd /var
→ cd /www
→ cd website-folder
→ git pull
→ npm run build
→ PM2 restart/reload
→ Hard Refresh

43. Same form multiple pages par ho to kya karna hai?

→ Form ko shared/reusable component mein rakho.

44. Same modal multiple places par ho to kya karna hai?

→ Modal ko shared component mein rakho.

45. Same component mein data different ho to kya karna hai?

→ Same component rakho aur Props/API se different data pass karo.

46. Repeated component ko API se data kaise denge?

→ Shared component ko API se required data fetch/pass karwa sakte hain.

47. Shared component mein changes karne ka benefit kya hai?

→ Ek jagah change karne se component use karne wali multiple places update ho sakti hain.
